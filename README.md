# ZKP Playground — Zero-Knowledge Proof เดโม่สำหรับสัมมนา

เดโม่แบบ interactive 2 ส่วน อยู่ในไฟล์ `index.html` ไฟล์เดียว (ไม่พึ่ง CDN/เน็ต):

1. **ถ้ำ Ali Baba** — อินตูอิชันของ ZKP แบบแอนิเมชัน: ผู้พิสูจน์เข้าถ้ำข้างใดข้างหนึ่ง ผู้ตรวจสุ่มเรียกทางออก ใครรู้คาถาออกถูกทางได้เสมอ ส่วน "คนโกง" โดนจับได้เรื่อย ๆ (โอกาสรอด 1/2ᴺ)
2. **Schnorr identification** — โปรโตคอล ZKP จริง รันสดด้วย JavaScript BigInt: คอมมิต → คำท้าทาย → ตอบ → ตรวจ `gˢ ≟ t·yᶜ (mod p)` บนจำนวนเฉพาะ 256 บิต (ตรวจแล้วด้วย Miller–Rabin) พร้อม "โหมดคนโกง" ให้เห็นว่าทำไม discrete log ถึงกันการหลอก

ฟีเจอร์บนเวที: โหมดพรีเซนต์ซูมจอ (ปุ่มขวาบน / กด P), คีย์ลัด Space/→ = ขั้นต่อไป, C = สลับคนโกง, R = รีเซ็ต, 1/2 = เปลี่ยนแท็บ, คลิกตัวเลข = ดูค่าเต็ม
